Who is the primary user?

The NL-first design looks very different depending on who's sitting in the chair.

A

Data Analyst / Engineer

Writes SQL daily. Knows what a JOIN is. Wants AI to accelerate their existing workflow — auto-write complex queries, spot patterns they'd miss, run analysis in parallel. Still wants to see the SQL.

Examples: BI analyst, data engineer, database admin, data scientist
B

Business / Domain Expert

Knows their data domain deeply (sales, ops, finance) but not SQL. Wants to ask questions in plain English and get answers — never wants to touch SQL. Charts and summaries only.

Examples: operations manager, sales lead, product manager, C-suite
C

Manufacturing / Industrial Engineer

Works with time-series sensor data, production lines, quality control. Needs SPC charts, anomaly detection, root cause analysis. Asks "why did line 3 fail at 2am?" and needs a real answer fast.

Examples: process engineer, quality manager, plant operations, IoT data analyst
D

All of the above — horizontal platform

DataIQ adapts to whoever is using it. Power users get SQL + agent depth. Business users get clean NL answers. Industrial users get SPC built-in. One tool, many personas.

Harder to ship fast — but biggest market

Pick one. This shapes the NL interface, chart defaults, and what "a great answer" looks like.
