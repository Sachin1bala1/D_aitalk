DataIQ Production Design — 4 Parallel Tracks

⚡ Track 1 — AI Speed & Intelligence

What changes
  • AgentLoop.ts — smarter tool selection, parallel tool calls where safe
  • resilience.ts — aggressive timeouts (8s/tool, 22s/round)
  • System prompt compression — inject only relevant schema sections
  • Fast-path: single-tool queries skip the full loop
  • Streaming progress bar in chat ("Running 3/8 tools...")
  • Context window guard — trim history to 20 turns, summarize older
Success criteria
  • First token: <1.5s from send
  • Simple query (SELECT + chart): <5s end-to-end
  • Complex analysis (8 tools): <25s
  • Zero infinite hangs on approval timeout (30s max)
  • Streaming tokens visible in UI within 500ms
Files: AgentLoop.ts, resilience.ts, AIChat.tsx, HarnessLifecycle.ts

📊 Track 2 — Visualization & Chart Editor

What changes
  • New ChartEditor.tsx — inline toolbar: type, axes, color, grouping, filters
  • New chart types: scatter matrix, heatmap, histogram, box plot, waterfall, control chart (X̄-R)
  • ArtifactChartViewer.tsx — click-to-edit, re-renders without AI round-trip
  • Chart → AI feedback: "explain this spike" button on every chart
  • Export: PNG, SVG, copy as image, copy data as CSV
  • Control chart overlays: 3σ limits, center line, spec limits (engineering-specific)
Success criteria
  • Chart type change: <100ms re-render
  • Axis swap: instant (no API call)
  • 8 chart types available
  • Control chart with SPC limits works on time-series
  • "Explain spike" → AI responds in <5s
  • Export to PNG works
Files: ChartEditor.tsx (new), ArtifactChartViewer.tsx, ChartPanel.tsx, chart tool in AgentLoop

🚀 Track 3 — Query Performance & DuckDB

What changes
  • DuckDB fully wired as first-class connection (CSV/Parquet/JSON → instant query)
  • Query result cache — LRU in-memory, same SQL + params = instant replay
  • Explain plan panel — visual tree, highlights slow nodes
  • Background query execution — non-blocking, progress shown in tab
  • Memory guard — auto-LIMIT 100k rows on unbounded queries, user override
  • Column profiling on demand — null%, cardinality, min/max/mean inline in schema tree
Success criteria
  • 1M row CSV query: <2s via DuckDB
  • Cached query replay: <50ms
  • No OOM on 10M row scan
  • Explain plan renders for any query
  • VirtualTable scrolls 1M rows at 60fps
Files: connection_manager.rs, query_executor.rs, DuckDB Tauri command, VirtualTable.tsx

🔌 Track 4 — Data Connectors

What changes
  • REST API connector — URL + auth (Bearer/API key/Basic), maps JSON response to table
  • File watcher — drop CSV/Parquet/Excel into a folder → auto-loads into DuckDB
  • Excel/XLSX import — native (via calamine Rust crate)
  • SSH tunnel — for remote PostgreSQL/MySQL behind firewall
  • Connection health monitor — reconnect on drop, visual indicator in sidebar
  • Schema refresh — manual + auto every 5min, diff shown to user
Success criteria
  • REST connector: any JSON API queryable within 30s setup
  • Drop a CSV → queryable in <3s
  • Excel import: 10k row sheet loads in <1s
  • SSH tunnel: connects to remote DB with 1 config step
  • Connection drop → auto-reconnect, no user action
Files: connection_manager.rs, new rest_connector.rs, ConnectionDialog.tsx, commands.rs
