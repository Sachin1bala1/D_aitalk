Daitalk

Support

Daitalk is a Windows desktop workspace for querying databases, exploring schemas, building dashboards, and using optional AI-assisted analysis.

If you need help with installation, setup, database access, dashboards, or safety and local-data controls, use the contact email below.

What to include in a support request

  • Your Windows version
  • Your Daitalk app version
  • A short description of the problem
  • Any exact error text shown in the app
  • Whether the issue happened during install, database use, AI use, or dashboard work

Common product notes

  • Native database access is available in the installed desktop app.
  • Browser preview mode is for UI preview only and does not provide native DB access.
  • AI-assisted destructive actions are intended to require explicit approval.
  • Safety & Local Data controls let users inspect and clear local app data.

This support page is intended for Microsoft Store and Windows release use.
