Daitalk Privacy Policy

Daitalk is a Windows desktop database workspace. This page explains what Daitalk stores locally on your device, what network services may be contacted when you enable optional features, and what controls you have over local app data.

Desktop-only database access

Native database access is available in the installed desktop application. Browser preview mode is intended for UI development and preview only and does not provide native database connectivity.

What Daitalk stores locally

  • Local query history
  • Visualization and intelligence telemetry
  • Benchmark records
  • Security audit events
  • Saved connection metadata used to restore saved connection entries

What is redacted before storage

Daitalk redacts string literals before storing query history locally. This reduces the chance that sensitive string values typed directly into queries are persisted in plain form in local history storage.

Credentials and secrets

Saved provider keys are intended to be stored using operating-system secure credential storage. Ordinary local history tables are not intended to act as a plaintext secret store.

What users can clear

Daitalk provides Safety & Local Data controls that allow users to inspect and clear:

  • Query history
  • Local telemetry
  • Benchmark records
  • Security audit events

Network connections

Daitalk may connect to user-configured databases and, when optional AI features are enabled by the user, to supported hosted AI providers.

Current supported hosted provider endpoints may include:

  • https://api.openai.com
  • https://api.anthropic.com
  • https://generativelanguage.googleapis.com
  • https://integrate.api.nvidia.com

If these optional features are not configured or used, those provider requests are not required for normal local desktop use.

AI-assisted actions

Daitalk includes optional AI-assisted features. AI-assisted actions that could modify data or schema are intended to require explicit user approval before execution.
